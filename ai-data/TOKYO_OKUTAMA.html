エリア概要

都会の喧騒から離れ緑豊かな清流が広がるエリア。最大の魅力はマイナスイオンたっぷりの大自然の中、初心者でも気軽に「手ぶら」で訪れることができるマス釣り堀が充実していること！面倒な事前準備は一切不要で、レンタル竿とエサですぐに釣りが始められます。澄み切った川のせせらぎを聞きながらのんびり糸を垂らせば、日々の疲れも吹き飛びます。釣ったばかりの新鮮な魚をその場で調理して味わえる施設が多いのも嬉しいポイント。美しい自然と触れ合いながら、心も体も満たされる癒しの休日を過ごせます。

スポット詳細

奥多摩湖

西多摩郡奥多摩町の多摩川上流部を小河内ダムでせき止めて造られた、東京都民の水がめ「小河内貯水池」こと奥多摩湖の広大なレイクフィールドです。豊かな原生林に囲まれた深い湖水には、サクラマス（ヤマメ）やニジマス、イワナといったトラウト類から、コイ、ヘラブナ、ワカサギ、ブラックバスまで多様な魚が生息し、漁協管轄外の無料フィールドとして陸っぱりから大物狙いが楽しめます（※ボート・フローターの持ち込みは全面禁止、急斜面やクマへの注意と立入禁止区域の厳守が必須）。大麦代園地や水と緑のふれあい館に無料駐車場・トイレ・食堂が整っています。

  • 所在地: 東京都奥多摩町
  • 水域・地域呼称: 多摩川水系
  • 別名・通称: 小河内貯水池
  • 座標: 35.777519, 139.017750
  • 登録魚種: ヤマベ
  • アクセス: 談合坂SICから約34分 (22.6km) / 道の駅 あらかわから車で 約40分 (26.5km)
  • 最寄りの釣具店: 市川商店 まで車で 約21分 (14.0km) / （有）横手商店 まで車で 約35分 (23.2km) / 秋川 中村おとり店 まで車で 約40分 (26.4km)
  • 地図: 奥多摩湖

平井川

あきる野市（旧・秋川エリア）から日の出町にかけて流れ、多摩川水系の秋川へと合流する支流・平井川の里山フィールドです。川幅が狭く穏やかな小河川ながら水質が良く、石底の瀬や小さな堰、淵にはオイカワ（ヤマベ）やカワムツ、アブラハヤ、ウグイ、コイ、さらには秋川漁協による放流が行われる春先のヤマメ・ニジマスや初夏のアユなどが生息しています（秋川漁協の遊漁券および禁漁期間を要確認）。川沿いは住宅地や細い生活道路が多いため、JR五日市線・東秋留駅や秋川駅周辺のコインパーキングを利用し、近隣の公園トイレを確認してマナー良く楽しみましょう。

  • 所在地: 東京都あきる野市
  • 水域・地域呼称: 多摩川水系
  • 管轄・関係漁協: 秋川漁業協同組合
  • 座標: 35.740556, 139.284706
  • 登録魚種: アユ、ウグイ、カワムツ、ヤマベ
  • アクセス: 日の出ICから約1分 (0.8km) / 青梅ICから約15分 (9.7km)
  • 最寄りの釣具店: わたやつり具店 まで車で 約6分 (3.8km) / DAISO イオンモール日の出店 まで車で 約1分 (0.6km) / DAISO あきるのプレイス店 まで車で 約2分 (1.5km)
  • 地図: 平井川

多摩川日野

日野市を流れる多摩川中流域、立日橋（多摩都市モノレール）や日野橋、JR中央線鉄橋から浅川合流点にかけて広がる開放的な河川敷フィールドです。川幅が広く、石が敷き詰められた瀬や深みのトロ場、テトラ帯、支流・浅川からの流れ込みなど変化が豊富で、アユの友釣りやオイカワ、ウグイ、コイ、ナマズ、スモールマウスバスなど多彩な川釣りが楽しめます（多摩川漁協の遊漁券が必要）。多摩都市モノレール・甲州街道駅や柴崎体育館駅から徒歩すぐで、河川敷の運動公園付近に公衆トイレも点在。帰りは日野・立川駅周辺の商業施設やラーメン店で食事を楽しめます。

  • 所在地: 東京都日野市
  • 水域・地域呼称: 多摩川水系
  • 管轄・関係漁協: 多摩川漁業協同組合
  • 座標: 35.685740, 139.397535
  • 登録魚種: アユ、ウグイ、ヤマベ
  • アクセス: 国立府中ICから約8分 (5.6km) / 八王子ICから約9分 (6.1km)
  • 最寄りの釣具店: 金子釣具店 まで車で 約5分 (3.3km)
  • 地図: 多摩川日野

落合川

東久留米市内を流れ、「東京の名湧水57選」にも選ばれた南沢湧水群を源流とする荒川水系（黒目川支流）の清流フィールドです。住宅街を抜けながら驚くほどの透明度を保つ浅い川底には水草が揺れ、アブラハヤやタカハヤ、カワムツ、オイカワ、コイなどの在来魚が泳ぐ姿を間近に観察でき、小物釣りや川遊びで親しまれています（※希少な水生生物の保護区域やバーベキュー禁止などのルールが定められているため、環境保全とマナーの徹底が必須）。西武池袋線・東久留米駅から徒歩またはバスでアクセスでき、川沿いの「落合川いこいの水辺」付近に公衆トイレがあります。

  • 所在地: 東京都東久留米市
  • 水域・地域呼称: 荒川水系 / 武蔵野
  • 座標: 35.757411, 139.536688
  • 登録魚種: オイカワ、カワムツ、コイ
  • アクセス: 大泉JCTから約11分 (7.5km) / 所沢ICから約12分 (7.7km) / 東久留米駅から徒歩 約8分
  • 最寄りの釣具店: タックルベリー BiG Berry多摩東久留米店 まで車で 約4分 (3.0km) / DAISO 東久留米駅前店 まで車で 約1分 (0.4km) / DAISO イトーヨーカドー東久留米店 まで車で 約1分 (1.0km)
  • 地図: 落合川

北多摩一号水門周辺

府中市小柳町の多摩川左岸、稲城市と府中市を結ぶ稲城大橋のすぐ上流に位置する「北多摩一号水門」周辺の淡水フィールドです。水門からの流れ込みと本流が交わるワンド状の深みやテトラ帯は、水温が安定しやすく小魚も多く集まるため、コイやヘラブナ、マブナ、オイカワ、ナマズ、スモールマウスバスなどの好ポイントとして知られています（多摩川漁協管轄のため遊漁券が必要）。河川敷の府中市郷土の森公園方面や緑地沿いに公衆トイレや駐車場がありますが、水門付近への路上駐車は厳禁です。西武多摩川線・競艇場前駅からも徒歩圏内です。

  • 所在地: 東京都府中市
  • 水域・地域呼称: 多摩川水系
  • 管轄・関係漁協: 多摩川漁業協同組合
  • 座標: 35.652272, 139.510034
  • 登録魚種: アユ、オイカワ、コイ、ニゴイ、マブナ、モロコ、ヨシノボリ
  • アクセス: 稲城ICから約1分 (0.6km) / 国立府中ICから約13分 (9.0km)
  • 最寄りの釣具店: キャスティング 府中店 まで車で 約4分 (2.7km)
  • 地図: 北多摩一号水門周辺

多摩川青梅周辺

青梅市の万年橋・調布橋から釜の淵公園、下流の羽村取水堰方面へと続く、渓流の趣と中流の開けた景色が交わる多摩川上中流域のフィールドです。大きく蛇行する清流には岩盤や淵、瀬が連続し、春から秋のヤマメやニジマス（本流トラウト）、初夏から秋のアユの友釣り、さらにはウグイやオイカワ、カジカなどが美しい景観の中で狙えます（奥多摩漁協の遊漁券および解禁期間・区間の確認が必須）。JR青梅線・青梅駅や東青梅駅から徒歩圏内で、釜の淵公園周辺に有料駐車場と公衆トイレが完備。帰りは青梅宿のレトロな町並みでそばやカフェを楽しめます。

  • 所在地: 東京都青梅市
  • 水域・地域呼称: 多摩川水系
  • 管轄・関係漁協: 奥多摩漁業協同組合
  • 座標: 35.785792, 139.255743
  • 登録魚種: アユ
  • アクセス: 日の出ICから約12分 (8.2km) / 狭山日高ICから約29分 (19.1km) / 青梅駅から徒歩 約12分
  • 最寄りの釣具店: 甲州屋 青梅店 まで車で 約1分 (0.6km)
  • 地図: 多摩川青梅周辺

御嶽・川井周辺

西多摩郡奥多摩町のJR青梅線・川井駅から御嶽（みたけ）駅、沢井駅周辺にかけて、巨岩と深い渓谷美が続く多摩川上流（御岳渓谷）の清流フィールドです。「名水百選」にも選ばれた透明度抜群の流れには、漁協の放流も盛んなヤマメやニジマス、イワナの渓流釣り（エサ・ルアー・フライ）やアユ釣りの好ポイントが点在するほか、川井・御岳エリアには初心者や家族連れが釣った魚をその場で炭火焼きで味わえる管理釣り場も揃っています（本流は奥多摩漁協の遊漁券が必要）。渓谷沿いに遊歩道と公衆トイレが整備され、帰りは名物の手打ちそばや澤乃井の酒蔵見学を楽しめます。

  • 所在地: 東京都奥多摩町
  • 水域・地域呼称: 多摩川水系 / 奥多摩
  • 管轄・関係漁協: 奥多摩漁業協同組合
  • 座標: 35.814186, 139.132662
  • 登録魚種: アユ
  • アクセス: 日の出ICから約33分 (21.7km) / イオンスタイル河辺から車で 約29分 (19.2km) / 鳩ノ巣駅から徒歩 約7分
  • 最寄りの釣具店: （有）横手商店 まで車で 約13分 (8.9km)
  • 地図: 御嶽・川井周辺

多摩川秋川合流

あきる野市と八王子市・福生市の境付近、清流・秋川が多摩川本流へと流れ込む「高月・拝島橋上流」周辺の広大な合流点フィールドです。澄んだ秋川の水と多摩川本流が交わる砂礫の瀬や淵、テトラ帯には、初夏から秋のアユ（友釣り・毛バリ釣り）やオイカワ、ウグイ、カワムツをはじめ、春先のヤマメ・ニジマス、コイ、ナマズなどが豊富に生息しています（多摩川本流側と秋川側で管轄漁協が異なるため、入釣場所に応じた遊漁券の購入が必須）。周辺の河川敷公園付近に駐車スペースやトイレが点在し、帰りは「秋川渓谷 瀬音の湯」や福生・拝島周辺のグルメを楽しめます。

  • 所在地: 東京都あきる野市
  • 水域・地域呼称: 多摩川水系
  • 管轄・関係漁協: 秋川漁業協同組合
  • 座標: 35.715092, 139.329772
  • 登録魚種: アユ

多摩川競馬場周辺

府中市是政の多摩川左岸、「ボートレース多摩川（多摩川競艇場）」や東京競馬場の南側にあたる是政橋上下流の河川敷フィールドです。すぐ上流の二ヶ領上河原堰から続く瀬や石積み、テトラ帯、橋脚のヨレが変化を作り出し、春から秋のオイカワやウグイ、アユ、コイ、フナ、ナマズ、スモールマウスバスなどが狙えます（堰周辺の禁漁区や多摩川漁協の遊漁規則を遵守）。是政橋近くの河川敷運動広場や府中市郷土の森公園周辺に公衆トイレと駐車場が整備されており、西武多摩川線・是政駅からも徒歩すぐ。帰りは府中本町や分倍河原駅周辺の飲食店で食事を楽しめます。
