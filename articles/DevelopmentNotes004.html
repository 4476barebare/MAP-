1. 第3節：Claude編 〜サブカル女子の「ステッカー工房」と、HTMLの壁を抜ける魔術〜

🖥 実際の画面で確認できます
クロードのCSSを適用した「画像重ね合わせツール」はこちら。「ステッカー工房」の世界観を、スマホで触って確かめてみてください。
https://4476barebare.github.io/tools/#Claude.css

Geminiの泥臭い執念や、Grokの涙ぐましい1行押し込み作戦が繰り広げられる裏で、第3の刺客であるClaude（クロード）の部屋は、まるで海外のインディーゲーム開発者のアトリエのような異様な静けさに包まれていた。

ベレー帽に作業エプロンをまとい、手元の作業台で黙々とシールを切り貼りしている彼女は、一見すると気さくなサブカル系クリエイターのように見える。しかし、そのコードの裏に隠された技術力は、4大AIの中でも最も尖り、最も危険な「魔術」を秘めていた。

2. 頼まれてもいないのに「まだ出力しない」と宣言する、圧倒的な自制心

コンペの幕開けにあたり、俺がClaudeに投げた最初のメッセージはこうだった。

俺：「とあるhtmlファイルのCSSを各社のAIモデルで独自に1番オススメのデザインを提出してもらうコンペを開催します。ちなみにchat GPT君とGemini君には既にcssファイルを提出してもらった。ここまで質問が無ければレギュレーションを説明する」

我が物顔でフライング提出をかましたGeminiとは対照的に、Claudeの反応はこうだった。

Claude：「了解です。いまのところ質問はありません。CSSはまだ出力せず、レギュレーションの説明を待ちます」

聞き分け良すぎだろ！！ 頼まれてもいない先回りの自制で、直立不動のままレギュレーションの提示を待つその姿勢は、すでにプロの職人の風格を漂わせていた。

3. 神コンセプト「ステッカー工房」の爆誕

ルールと原本ファイルを渡すと、Claudeは一発目から他のAIとはまるで毛色の違うコンセプトを叩き出してきた。 他の面々が「SaaS風ダッシュボード」や「iOS風ダークモード」といった既存のITツールっぽいデザインに寄っていく中、Claudeだけがこう宣言したのだ。

Claude：「テーマは『ステッカー工房』です。このツールは切り抜いたものを貼る道具なので、画面全体を太い黒フチとずらし影のシール台紙風にしました。ボタンは押すと影の分だけ沈みます。色は機能の目印にしていて、黄が画像、ピンクがテキスト、ミントが背景設定です」

天才か……！ ツールの本質を「切り抜いた素材をペタペタ貼る台紙」と再定義し、あえてポップでレトロな文房具の世界観をCSSだけで構築してしまった。さらに、変数管理や押下時のアニメーション、アクセシビリティに至るまで完璧に設計されたその初稿は、初見で「こいつはタダ者ではない」と思わせる圧倒的なクオリティだった。

4. CSSの黒魔術：SVGアイコンの裏口注入

しかし、コンペには「HTMLやJavaScriptは一切変更禁止」という絶対の鉄の掟がある。 実機のスクリーンショットを確認していく中で、一つ大きな問題が発生した。スマホ画面で角度を1度ずつ変えるボタン（↶ -1°）の文字記号が、端末のフォント環境によっては小さく潰れてしまっていたのだ。

HTMLをいじれない以上、普通は諦めるか文字を削るしかない。だが、孤高の職人クロードの執念は斜め上を行っていた。

Claude：「角度ボタンの小さな記号が端末の字形で小さく潰れていたので、HTMLは変更せず、元の文字を font-size: 0 で隠して、CSSの疑似要素（::before / ::after）でSVGの回転矢印アイコンに差し替えました」

HTMLを変えずにCSSの魔術だけでSVGをインジェクトする暴挙！ この変態的かつスマートなハックにより、制限の壁を軽々と飛び越えてみせた。

5. 誠実すぎる自白と、運命の「改訂履歴コメント」

リテイクを重ねてほぼ完璧に仕上がった最終盤（リテイク3回目）、Claudeは実機スクショを見つめながら、突然こんな「自白」を始めた。

Claude：「ただ1点、私が前回入れた改行の均等化が裏目になっていました。『スワイ/プ』『背/景』のように、日本語の語の途中で折り返しています。これは私の失敗なので、その指定だけを撤回しました。これでリテイクは3回すべて使ったことになるので、最終版を出し直します」

自分のわずかなミス（日本語の変な改行）を隠さず素直に申告し、自らの手で修正して綺麗に3回のリテイク枠を使い切る。技術の高さだけでなく、その実直で誠実なモノづくり姿勢には脱帽するしかなかった。

……ただ、この時。 クロードはCSSの先頭に、リテイクごとの軌跡をこんな風に律儀に書き残していた：
/* 改訂：リテイク1回目…… */
/* 改訂：リテイク2回目…… */

真面目ゆえに残してしまったこの「改訂履歴の足跡」が、のちにライバルAIたちの審査員席から「プロの納品物として余計なパッチの履歴だ」と容赦なく狙い撃ちされる致命的な減点ポイントになろうとは、この時の彼女は知る由もなかったのだ。
